# ⚡ IonTech - Links

Bem-vindo ao repositório da página de links da **IonTech**! 

Como o foco principal do meu GitHub é o desenvolvimento de software, decidi utilizar este espaço para hospedar uma solução construída do zero para o meu trabalho autônomo com **eletrônica especializada e manutenção de hardware**. 

Em vez de recorrer a plataformas prontas (como Linktree), resolvi colocar a mão na massa e desenvolver uma Single Page Application (SPA) customizada, leve e responsiva para centralizar o atendimento, redes sociais e vitrine de insumos da assistência.

## 🛠️ Tecnologias Utilizadas
A página foi construída sem frameworks, focando em performance e em uma interface que remete à tecnologia:
* **HTML5:** Estruturação semântica.
* **CSS3:** Estilização responsiva, aplicação de *Glassmorphism* (efeito de vidro) e texturas modulares feitas puramente com código (sem imagens de fundo pesadas).
* **JavaScript (Vanilla):** Lógica simples para alternância de menus e exibição dinâmica dos links de afiliados na mesma tela, garantindo uma navegação fluida.

## 🔌 Sobre a IonTech
A IonTech é minha frente de atuação autônoma voltada para a manutenção de equipamentos eletrônicos (como consoles e computadores). É onde a precisão e a lógica que aplico escrevendo código se encontram com a prática de diagnósticos e reparos na bancada.
